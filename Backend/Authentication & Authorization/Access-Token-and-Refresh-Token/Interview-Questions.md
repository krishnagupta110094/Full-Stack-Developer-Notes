# 🎯 Access Token & Refresh Token - Interview Questions & Answers

> Core interview questions covering Access Tokens, Refresh Tokens, and token lifecycle management.

---

### Q1: What is an Access Token?
**Answer:**  
An Access Token is a short-lived credential used to authenticate requests to protected APIs.

---

### Q2: What is a Refresh Token?
**Answer:**  
A Refresh Token is a long-lived credential used to obtain a new Access Token when the existing Access Token expires.

---

### Q3: Why do we use Refresh Tokens?
**Answer:**  
Refresh Tokens allow users to remain logged in without requiring them to enter their username and password every time the short-lived Access Token expires.

---

### Q4: What is the main difference between an Access Token and a Refresh Token?
**Answer:**  
An **Access Token** is used for **API access**, whereas a **Refresh Token** is used exclusively for **getting a new Access Token**.
